# Teacher Mode

Teacher Mode permite preparar o retirar de una vez las ayudas visuales de una
clase, demostración o grabación. No sustituye herramientas ni conserva una
segunda copia de sus ajustes: coordina los estados de los módulos existentes.

## Comportamiento

La configuración permite incluir o excluir:

- Cursor Highlight;
- Click Effects;
- Keystrokes;
- Spotlight;
- Magnifier;
- modo de anotación de Lekhini.

Cursor, clics, atajos y anotaciones están incluidos de forma predeterminada.
Spotlight y Magnifier son opcionales porque oscurecen o capturan una región de
la pantalla y no resultan adecuados para todas las clases.

Al activar Teacher Mode se encienden los módulos incluidos y se apagan los
excluidos. Al desactivarlo se apaga el conjunto. Cambiar una inclusión mientras
el modo está activo aplica inmediatamente la nueva composición.

El botón `T` de la barra proporciona acceso rápido. La sección
**EduTicTac / Teacher Mode** contiene el interruptor general y la composición.

## Permisos

Antes de activar una composición que incluya clics o atajos, la interfaz
comprueba Input Monitoring. Magnifier conserva su gestión independiente del
permiso Screen Recording. Los permisos no se solicitan si la herramienta no
forma parte de la composición.

## Persistencia

Se guarda la composición elegida, pero Teacher Mode arranca desactivado al
iniciar Lekhini. Esto evita que una apertura normal comience a observar eventos
o capturar una región sin una acción explícita del usuario.
